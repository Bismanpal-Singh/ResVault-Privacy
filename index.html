Privacy Policy for ResVault Extension

Last updated: [05/01/2025]

The ResVault Chrome extension is a lightweight blockchain wallet designed to interact with ResilientDB. It enables users to create and manage accounts, submit transactions, and interact securely with the blockchain network.

1. Information We Collect

The extension does not collect, store, or transmit any personal information, browsing history, or user data. All data remains local within the user's browser.

2. Permissions Used

  • storage – Used to store account data and settings locally.
  • activeTab – Allows interaction with the active browser tab when required by user actions.
  • tabs – Used to manage or open blockchain-related tabs.
  • scripting – Enables UI enhancements or interactions with ResilientDB pages.
  • host_permissions – Specifically for https://cloud.resilientdb.com/* to submit transactions.

3. How We Use Data

All interactions are local and user-initiated. The extension does not:

  • Track or log interactions
  • Store history or analytics
  • Transfer data to external servers

4. Security

ResVault does not require authentication. All requests are securely sent via HTTPS.

5. Third-Party Services

No third-party services are integrated. The extension only communicates with https://cloud.resilientdb.com.

6. Updates

Any updates to this policy will be reflected here and in the source repository.

7. Contact
